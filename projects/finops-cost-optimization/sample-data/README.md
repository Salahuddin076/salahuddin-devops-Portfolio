# Sample data (synthetic)

Everything in this directory is **synthetic**, generated by:

```bash
python3 -m finops generate --out sample-data --seed 42 --start 2026-07-01 --days 90
```

The generator is deterministic: the same seed, start date and day count produce
byte-identical files (asserted by `tests/test_generator.py`). Regenerate rather
than hand-editing.

| File | Rows | What it represents |
|---|---|---|
| `billing.csv` | ~3,400 | FOCUS-like daily billing export, 2026-07-01 to 2026-09-28 |
| `utilization.csv` | 17 | Per-instance CPU / memory summary (CloudWatch-style) |
| `ebs_volumes.csv` | 8 | EBS volume inventory (DescribeVolumes-style) |

## The fictional estate

Four teams (`payments`, `search`, `platform`, `data`) in one account in
`us-east-1`. The data is shaped so that every analysis has something to find:

- **Tag hygiene**: data transfer, a log bucket, an orphaned `m5.large` and an
  unattached volume carry no tags; one EKS node launched mid-period carries only
  `team`; one OpenSearch node is tagged `team=Search` (casing drift, merged by
  normalisation).
- **Rightsizing**: oversized `m5.2xlarge` API servers (p95 CPU ~25%), an idle
  staging node and dev ETL box, a mostly idle notebook `r5.xlarge`, and x86
  `m5`/`c5`/`r5` instances with Graviton equivalents. Two `m7g` instances show an
  estate that has already started migrating.
- **Commitments**: four instances are covered by an existing (fictional) Compute
  Savings Plan; a weekday-only batch box and weekend scale-in on EKS nodes give
  the hourly on-demand baseline a visible floor below its mean.
- **Forecast/budget**: usage-driven services (S3, NAT, data transfer) grow
  ~0.4% per day and a fourth EKS node appears on day 45.

## Billing columns

`BillingPeriodStart, ChargePeriodStart, ChargePeriodEnd, ServiceName, ResourceId,
ResourceType, RegionId, x_InstanceType, UsageQuantity, PricingUnit, ListCost,
BilledCost, EffectiveCost, ChargeCategory, PricingCategory, Tags`

- Savings Plan coverage follows FOCUS conventions: covered usage has
  `BilledCost = 0` and a discounted `EffectiveCost`; a daily `Purchase` row
  carries the plan fee as `BilledCost` with `EffectiveCost = 0`.
- `Tags` is a JSON object (`{"app":"api","env":"prod","team":"payments"}`) or
  empty when untagged.
- `x_InstanceType` is a custom (`x_`-prefixed) column; real FOCUS exports
  don't have it and the toolkit doesn't require it.
- Prices are illustrative, approximate us-east-1 on-demand list prices from
  `finops/pricing.py`. Verify against current AWS pricing. Nothing here is a
  real bill.
